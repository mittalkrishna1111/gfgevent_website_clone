### GeeksforGeeks Student Chapter — Bennett University (Marvel × Web Design)

> *"Earth's Mightiest Geeks Assemble to Defend the Digital Realm."*

A cinematic, interactive, and event-ready web experience built with **100% Pure Vanilla HTML, CSS, and JavaScript** for the flagship hackathon and technical symposium organized by the **GeeksforGeeks Student Chapter, Bennett University** (Greater Noida).

---

## ⚡ Zero-Dependency Architecture

This project strictly adheres to pure client-side web fundamentals:
- **HTML5**: Semantic markup, accessible elements, and zero inline JavaScript.
- **Pure CSS3**: Custom design system in `css/style.css` featuring glassmorphism, Marvel color palettes, comic halftone dots, hexagonal energy forcefields, and responsive layout grids. **Zero Tailwind CSS, zero CSS frameworks**.
- **Vanilla JavaScript**: All dynamic functionality, state handling, audio synthesis, and particle physics in `js/script.js`. **Zero React, zero Next.js, zero Three.js, zero GSAP, zero external CDNs, zero AI APIs, zero backend/database dependencies**.

## 🚀 How to Run

### Method 1: Direct File Launch (No Setup Required)
Simply double-click or open **`index.html`** in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari).

### Method 2: Local HTTP Server (Optional)
```bash
# Using Python 3
python -m http.server 8000

# Or using npx
npx serve .
```
Visit `http://localhost:8000` in your browser.
